RUN IN VS CODE
==============

1. Open this BSWEB folder in VS Code
2. Open Terminal once and run:  npm install
3. Press F5  (choose "Run website")

Wait 2 seconds — browser opens at http://localhost:8080
Keep the terminal open while you view the site.

OR double-click:  run.cmd

If port 8080 is busy, close other terminals running the site.
